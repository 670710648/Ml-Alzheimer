STACKING DESIGN
------------------------------------------------------------------------
Each candidate stacks three base learners; a logistic-regression meta-learner combines out-of-fold outputs (probabilities where available and SVM decision scores otherwise). Candidate combinations are compared by 3-fold validation F1 on each training partition, using the same one-standard-error/gap rule as the individual model searches; only the selected candidate is scored on that holdout.
For both model hyperparameters and stack candidates, choose the smallest nonnegative train/CV F1 gap among choices within one standard error of the peak CV F1; ties prefer higher CV F1.
The candidates introduce different decision patterns: a linear logistic baseline, RBF-SVM margins, shallow-tree interactions, MLP nonlinearities, and (in one candidate) bagged random trees. This is a practical diversity rationale; the reported CV scores show which combination is actually preferred for each split.
